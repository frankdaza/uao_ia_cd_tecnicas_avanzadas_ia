# Atencion a ninos y neonatos

**Pediatria** integral, UCIN y seguimiento del recien nacido. *Atienden a
ninos* desde el primer control hasta adolescencia, con ruta de vacunacion y
crecimiento.

La unidad de pediatria prioriza acompanamiento familiar, lactancia y lineas
de cuidado para menores. Si busca *pediatria* o cuidado infantil, esta es
la linea adecuada.
